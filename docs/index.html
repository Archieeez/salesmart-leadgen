Cara membaca angka-angka ini
  • Kategori spesifik jauh mengalahkan generik: consulting 60% vs company 12% cakupan telepon.
  • Denpasar menghasilkan entri terbanyak tapi teleponnya paling sedikit — banyak belum tentu berkualitas.
  • 145 duplikat lolos dedup berbasis ID karena PT. Bakti Mandiri Perkasa dan PT BAKTI MANDIRI PERKASA punya osm_id berbeda dengan telepon sama.
  • Batang abu-abu di grafik terakhir (Traveloka, Tokopedia, Blibli) adalah perusahaan besar yang tidak punya tim sales lapangan — tidak cocok untuk Salesmart.
  • Hanya 27 dari 991 entri (3,2%) cocok profil klien ideal. Ini baseline pembanding untuk menilai apakah Places API nanti lebih baik.
